# Imersão Dev Alura — HTML, CSS e JavaScript

Projeto desenvolvido durante estudos de desenvolvimento web, utilizando HTML, CSS e JavaScript para criar uma interface interativa.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Abra `index.html` no navegador ou utilize o Live Server no VS Code.

## Arquivos principais

- `index.html` — estrutura da página.
- `style.css` — estilos.
- `app.js` — lógica e interações.
- `dados.js` — dados utilizados pela aplicação.

Projeto acadêmico/de estudo.
